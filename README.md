# hxyfront-62012 纺织染整寄样台账

源提示词编号：7

染整实验室的寄样台账前端：每次寄样留存面料、染料百分比、克重、浴比与色差快照；业务员改单后，旧寄样自动作废留档、不可回签。支持按客户订单收窄列表、区分在寄 / 可回签 / 已回签 / 已作废、补录新样、登记客户反馈并导出当前筛选结果（CSV）。

## 代码分层

- `src/domain/ledger.ts` — 寄样判断：状态推导、工艺指纹比对、回签资格、CSV 生成（纯函数）
- `src/storage/ledgerStore.ts` — 本地存档：localStorage 读写、示例数据、重置
- `src/App.tsx` — 页面交互：筛选、补录、反馈、回签、变更工艺、导出

状态不落库，随订单工艺实时重算：寄样快照与订单现行工艺不一致即「已作废」；一致时无反馈为「在寄」、有反馈为「可回签」；回签后为「已回签」且不再受改单影响。所有变更自动写入 localStorage，重开页面可接着处理。

## 技术栈

React + Vite + TypeScript
